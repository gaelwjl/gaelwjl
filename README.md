### Wenjun (Gaël) Liu

Senior Research Engineer at Google DeepMind, working on large-scale model training — distributed pre/post-training, distillation, and RL for multimodal systems. Core contributor to the [Gemma](https://arxiv.org/abs/2503.19786) and [Gemini](https://arxiv.org/abs/2507.06261) model families. Previously multimodal ML serving and generative AI at YouTube, and high-performance C++ and NLP at J.P. Morgan.

**Background:** Applied Mathematics (École Polytechnique, Sorbonne University).

**Interests:** distributed training, distillation, post-training RL, C++ performance optimization.
